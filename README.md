# Scavenger Hunt

A video scavenger hunt game where teams compete to act out and capture scenarios on video.

## Overview

- Teams of 2-6 players compete to complete video challenges
- Game keeper manages the game and awards bonus points
- Real-time scoreboard tracks team progress
- Presentation mode for reviewing all captured videos
